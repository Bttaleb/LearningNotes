## Best Practices
1. variable names should begin with lowercase letters
2. avoid naming identifiers starting with underscore
3. name of identifiers should make clear what the value they hold means
4. avoid abbreviations
5. for variable declarations, use a comment to describe what a variable is going to be used for 
	ex. Does the text "Hello World!" have 10, 11, 12 characters?
	- depends on whether we're including whitespace or punctuation
	- rather than naming a variable `numCharsIncludingWhitespaceAndPunctuation`, place a comment to help the user
	```cpp
	// a count of the number of chars in a piece of text, including whitespace & punctuation
	int numChars {};
	```
