The fundamental building blocks for writing meaningful code that performs calculations and manipulations on data

Consider the following statements:
```cpp
std::cout << "Hello World!";
int x {5};
```
"Hello World!" and '5' are **literals** or, a fixed value inserted directly into source code

Literals and variables have a *value* and *type*
- Unlike a variable, the value of a literal is fixed and cannot be changed
- The literal `5` always has value `5`, which is why literals are called constants
