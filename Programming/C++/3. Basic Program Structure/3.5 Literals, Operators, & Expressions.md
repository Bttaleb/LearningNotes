The fundamental building blocks for writing meaningful code that performs calculations and manipulations on data

Consider the following statements:
```cpp
std::cout << "Hello World!";
int x {5};
```
"Hello World!" and '5' are **literals** or, a fixed value inserted directly into source code

Literals and variables have a *value* and *type*
- Unlike a variable, the value of a literal is fixed and cannot be changed
- The literal `5` always has value `5`, which is why literals are called constants

```cpp
#include <iostream>                                                

int main() {
	std::cout << 5 << '\n';     // print the value of a literal
	
	int x { 5 };                
	std::cout << x << '\n';     // print the value of a variable
	return 0;
} 
```

`std::cout << 5` -> Compiler generates code that causes std::cout to print value 5
`int x { 5 }` -> Creates a variable named `x` with value init. to `5`, compiler geenrates code that causes std::cout to print value at the memory location of `x` (which has value 5)

Both outputs do the same thing (print 5), but 
- in the case of the literal:
	value `5` can be printed directly
- in case of the variable
	value `5` must be fetched from the memory the variable represents

## Operators
An operation is a process involving zero or more inputs (*operands*) that produces a new value (*output value*). The operation to be performed is denoted by a symbol called an **operator**

In the following program, the literals `1` and `2` are *operands* to the plus (`+`) operator, producing the output `3`

```cpp
std::cout << 1 + 2 << '\n';
```
