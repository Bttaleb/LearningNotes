### How do programs actually produce results?
By manipulating (reading, changing, and writing) data. **Data** is any information that can be moved, processed, or stored by a computer

- Programs are collections of instructions that manipulate data to produce a desired result
A single piece of *data* is called a **value**
- Values placed in single quotes are interpreted as *character values*
- Values placed in double quotes are interpreted as *text values*
- Values placed directly in source code are called **literals**

## Random Access Memory (RAM)
The OS loads the program into **RAM**
	think of RAM as a series of numbered boxes, used to store data while a program is running
### Objects and Variables
	in C++, direct memory access is discouraged
Instead, we access memory *indirectly* through **objects**
**Objects** represent a region of storage (RAM or CPU register) that can hold a value
Rather than "go get value stored in mailbox number 8324", we can say "go get the value stored by this object"
	This helps us focus on using objects to store & retrieve values without worrying about where in memory it's being placed
An object with a name is called a **variable**
- Objects are used to store values in memory
- Variables are objects with names (identifier)
We declare **definition** statements to tell the compiler that we want to use a variable

```cpp
int x;
```
### Compile-Time
When encountering a definition statement, compiler notes that we want a variable with name `x`

### Variable Creation
During **runtime** (when program is loaded into memory), objects are given storage locations (RAM or CPU registers) used to store values
Reserving storage for an object's use is called **allocation**

### Data Types
Determines what kind of values an object will store
Data type of an object must be known at compile-time
