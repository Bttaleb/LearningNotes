## 5️⃣ Pseudocode
<!-- Translate the case table directly. No real syntax yet. -->
```
init: 
k = 1 (where next unique gets written)
i (scanner reading each element)
for i = 1 ... numsSize - 1 (start at 1 because we read nums[i-1])
	if nums[i] != nums[i-1]
		copy VALUE nums[i] into slot k
		k++ (advance write slot)
return k
```

**Invariant / why it's correct:**
at every step, `nums[0..w]` holds exactly the unique values we've seen in `nums[0..r-1]` in sorted order. When `r` reaches the end, `nums[0..w]` is the full unique set.

**Complexity:** Time O(n) · Space O(1)

## 6️⃣ Build (Code)
```c
int removeDuplicated(int* nums, int numsSize) {
	int i, k=1;
	for (i = 1; i < numsSize; i++) {
		if (nums[i] != nums[i-1]) {
			nums[k] = nums[i];
			k++;
		}
	}
	return k;
}
```
