Every node in a list contains:
- Its value
- a pointer to the next node
**What the machine sees at each step:** 
list1 and list2 are lists full of nodes `0...50`
let `a` and `b` be a the current heads in each list

Before correction:

| Input                            | Action                         |
| -------------------------------- | ------------------------------ |
| both lists empty/NULL            | both lists done                |
| `a` NULL & `b` node              | list1 done, list2 has nodes    |
| `a` node & `b` NULL              | list1 has nodes, list2 done    |
| `a` node & `b` node              | both lists have nodes, compare |
| both present, `a.val` <= `b.val` | `a`'s node is next             |
| both present, `a.val` > `b.val`  | `b`'s node is next             |
After correction

| Input                             | Action                                      |
| --------------------------------- | ------------------------------------------- |
| 1. both NULL                      | stop -> return merged list                  |
| 2. exactly one empty              | attach the other tail's remainder           |
| 3. both present, `a.val <= b.val` | tail.next = a; a = a.next; tail = tail.next |
| 4. both present, `a.val > b.val`  | tail.next = b; b = b.next; tail = tail.next |

## 5️⃣ Pseudocode
<!-- Translate the case table directly. No real syntax yet. -->
```
dummy = new node
tail = dummy

while (list1 != NULL && list2 != NULL) // 1. NULL check out of the way
	if (list1->val <= list2->val) {
		tail->next = list1->val
		list1->val = list1->next;
	} else {
		tail->next = list2->val
		list2->val = list2->next;
	}
	tail = tail->next


```

**Invariant / why it's correct:**
Each step considers if there's a value available for comparison, splicing and returning the lesser value first


**Complexity:** Time O(n+m) · Space O(1)
