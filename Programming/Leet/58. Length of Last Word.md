**Problem in my own words:**
A *word* is a maximal substring of non-space characters. Given a string `s` consisting of words and spaces, return the length of the last word in the string

**Formal statement:**
- Input: `s` whose length >= 1
- Output: length of last word in string `s`
- Kind of problem: decision (yes/no) | search (find one) | optimization (find best) | **counting**
<!-- For string problems: alphabet Σ = { }, language L = { w ∈ Σ* | ... }, question: is w ∈ L? -->

**Rules / properties a correct answer must satisfy:**
1. spaces must be skipped
2. answer must be the last word in the string
3. return length of the word if `s` is all non-space characters

**Constraints that matter:**
- n ≤ 10,000
- Values (what the data can contain): 
  `s` contains only English letters and spaces
  `s` is at least one word
- What the constraints change in practice (buffer sizes, which complexities pass): `int` (count) can hold numbers up to 2.14 billion, so a single pass will suffice

## 6️⃣ Build (Code)
```c
int lengthOfLastWord(char* s) {
	int end = strlen(s) - 1;
	int count = 0;
	for (int i = end; i >= 0; i--) {
		if (s[i] == ' ') {
			if (count > 0) {
				return count;
			}
		} else {
			count ++;
		}
	}
	return count;
}
```
