## 1️⃣ Define (Understand)
<!-- Restate it without copying the prompt. Turn every vague word ("valid", "correct order", "matching") into something a program can check. -->

**Problem in my own words:**
Given two strings `needle` and `haystack`, return the first occurrence of the string `needle` in `haystack`. If `needle` is not part of `haystack` return -1

**Formal statement:**
- Input: 2 lowercase strings <= 10^4 characters
- Output: first occurrence of `needle` if found, -1 if not
- Kind of problem: decision (yes/no) | **search (find one)** | optimization (find best) | counting
<!-- For string problems: alphabet Σ = { }, language L = { w ∈ Σ* | ... }, question: is w ∈ L? -->

**Rules / properties a correct answer must satisfy:**
1. must include -1 if `needle` not found
2. first occurrence of `needle` in `haystack`
3. 

**Constraints that matter:**
- n ≤ 10^4
- Values: `n` = strlen(haystack), `m` = strlen(needle), `i`: start of haystack, `j`: how many chars. of needle match from the start, `j==m`: accept state
- What the constraints change in practice (buffer sizes, which complexities pass): 

**Examples I traced by hand:**
<!-- Include at least one example per rule above that breaks only that rule -->
```
Input: needle = "sad", haystack = "sadnotsad"
Output: "0";
Why: sad occurs at index 0 and 6, but first occurrence is 0

Input: needle = "leeto", haystack = "leetcode"
Output: -1
Why: "leeto" did not occur in "leetcode"

```
