# Valid Parentheses

## 🧩 Problem in My Own Words
Given a string of only `()[]{}`, decide whether every bracket closes properly. Each closer must match the **most recently opened, still-unclosed** bracket of the same type, and nothing can be left open at the end.

**Constraints that matter:**
- 1 ≤ s.length ≤ 10⁴
- Values: only the six bracket characters
- Edge cases implied: odd length can never be valid; the string can start with a closer

**Examples I traced by hand:**
```
Input:  "([)]"
Output: false
Why:    push ( → push [ → see ')' but top is '[' → mismatch
        Counts are balanced, but the ORDER is wrong — this is why counting fails.

Input:  "{[]}"
Output: true
Why:    push { → push [ → ']' pops [ → '}' pops { → stack empty
```

## 🐢 Brute Force
**Idea:** Repeatedly delete every adjacent `()`, `[]`, `{}` pair until nothing changes. Valid if the string ends up empty.

**Complexity:** Time O(n²) · Space O(n)

**Why it's not enough:** Each pass is O(n) and might remove only one pair, so you can need up to n/2 passes. The stack does the same "remove innermost pair" work in a single pass.

---

## 🚀 Optimal Approach
**Key insight (one sentence):**
> The stack holds exactly the brackets that are still open, in order, so every closer only has to check the top.

**Algorithm:**
1. Map each closer to its opener: `{')': '(', ']': '[', '}': '{'}`.
2. For each char: if it's an opener, push it. If it's a closer, the stack must be non-empty and its top must be the matching opener, so pop it. Otherwise return false.
3. At the end, return `stack is empty`.

**Invariant / why it's correct:**
After processing `s[0..i]`, the stack holds the unmatched openers of that prefix in order, and everything else in the prefix has been matched correctly. A closer can legally match only the innermost open bracket, which is the top of the stack.

**Complexity:** Time O(n) · Space O(n)
<!-- Each char is pushed/popped at most once → O(n). Worst case "((((((" keeps all n on the stack. -->

---

## 💻 Code
```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []
        for ch in s:
            if ch in pairs:                      # closer
                if not stack or stack[-1] != pairs[ch]:
                    return False
                stack.pop()
            else:                                # opener
                stack.append(ch)
        return not stack
```

**Optional early exit:** `if len(s) % 2: return False`

## 🎓 Coursework Connections
- [[Theory of Computation]]: balanced brackets (the Dyck language) are the textbook **context-free but not regular** language. You can show it with the pumping lemma on `(ⁿ)ⁿ`. A DFA has finite memory and can't count unbounded depth, but a **pushdown automaton** (a DFA plus a stack) can. This solution *is* a PDA.
- [[Operating Systems]]: the call stack works the same way. Nested function calls return in LIFO order.
- [[Software Engineering]]: compilers, JSON parsers, and linters all do bracket matching during parsing.

## 🧠 Takeaways
**What I'd tell myself before attempting this again:**
Counting brackets isn't enough, because order matters. When the most recent thing has to be resolved first, use a stack.

**Mistake to never repeat:**
Forgetting the final `return not stack`, which lets `"(("` pass. Also popping without checking that the stack is non-empty.
