# Context-Free Languages (CFL)

A language is **context-free** if some **context-free grammar** generates it.
	Equivalently: some [[pushdown-automata|pushdown automaton (PDA)]] recognizes it.

One level above regular in the Chomsky hierarchy:
	every regular language is context-free, but not every context-free language is regular.

---

## Context-Free Grammar (CFG)

A CFG is a 4-tuple: **(V, Σ, R, S)**

| Symbol | Meaning |
|--------|---------|
| V | Finite set of variables (nonterminals) |
| Σ | Alphabet (terminals), disjoint from V |
| R | Rules of the form A → w, where A ∈ V and w ∈ (V ∪ Σ)* |
| S | Start variable (S ∈ V) |

**Context-free** = the left side of every rule is a single variable, so a variable can be replaced no matter what surrounds it (its "context").

A grammar **generates** strings: start at S and keep applying rules until only terminals are left.

---

## Three ways to describe the same language

| Approach | What it says | Example: balanced brackets |
|---|---|---|
| **Grammar** (generative) | How to *build* every string in L | `S → ε \| (S)S \| [S]S \| {S}S` |
| **Rules / properties** (declarative) | What every string in L *must satisfy* | each closer has the same type as the most recent unclosed opener; nothing left open at the end |
| **Automaton** (procedural) | How to *check* a string step by step | a PDA: push openers, pop on closers |

All three describe the **same set of strings**.

---

## CFG ⇔ PDA

**Theorem:** a language is context-free ⇔ some PDA recognizes it.

A PDA is a finite-state machine **plus a stack**. The stack is unbounded memory with LIFO access, which is exactly what a [[dfa|DFA]] is missing.

**Deterministic CFLs** (recognized by a deterministic PDA: exactly one move per input symbol and top of stack) can be decided in **one left-to-right pass, O(n) time**.

---

## Why some CFLs aren't regular

A DFA has finitely many states, so it can't remember an unbounded amount.

Example, balanced brackets: the prefixes `(`, `((`, `(((`, … each need a different continuation to be accepted, so they're pairwise distinguishable (Myhill–Nerode). Infinitely many prefixes would need infinitely many states, so no DFA exists.

Gut check: *as the input grows, does what I need to remember grow without limit?* If yes, it's probably not regular.

Trap: **bounded** counting is still regular (count mod 3, nesting depth ≤ 5). Only **unbounded** counting forces you past regular.

---

## Hierarchy (what machine you need)

| Class | Machine | In code |
|---|---|---|
| Regular | [[dfa\|DFA]] / [[NFA]] | O(1) extra space: flags, a state enum |
| One-counter (between the two) | DFA + one counter | a single integer, e.g. one bracket type |
| Context-free | [[pushdown-automata\|PDA]] | a stack, O(n) space |

The class of the problem tells you the **minimum** machinery any correct solution needs.

---

## Where this shows up
- [[20. Valid Parentheses]]: balanced brackets (the Dyck language) is the classic deterministic CFL; the solution *is* a PDA
- Parsers for programming languages: nested blocks, expressions, and matching delimiters are context-free
